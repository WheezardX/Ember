# Architecture Decision Records

Short, numbered records of load-bearing technical decisions. One decision per
file, named `NNNN-short-title.md`, numbered sequentially and never reused.

An ADR states: context, the decision, alternatives considered, and consequences.
Supersede rather than edit — a new ADR that references the one it replaces.

Numbering continues the Terrain repo's sequence (ember was split out of it), so the
first ember-owned record is 0006. Earlier ADRs live in the Terrain repo; 0005 (the
terrain/ember split) is copied here for context.
